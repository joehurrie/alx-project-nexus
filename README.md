# EcoWise

## About
-EcoWise is a mobile-first sustainability web platform designed to help consumers make climate-conscious choices in their everyday shopping. By combining real-time product data, transparent environmental scoring, and community-driven insights, the app transforms routine purchases into opportunities for impact. Users can scan barcodes or search for products to instantly view sustainability scores based on emissions, packaging, sourcing, and ethical practices using green rates. The platform then suggests eco-friendly alternatives and tracks personal metrics like CO₂ saved and plastic avoided, offering a tangible sense of progress. EcoWise also includes a community section where users share tips, rate products, and engage in discussions—building trust and collective awareness around sustainable living.

## Running Locally

1.  Create a `.env` file by copying the `.env.example` file.
2.  Add your Gemini API key to the `.env` file as `GEMINI_API_KEY`
3.  Run `npm install` to install the dependencies.
4.  Run `npm run dev` to start the development server.


# Project Nexus Review

## Overview
This programme has been a transformative experience in my frontend development journey. As part of the ProDev Frontend Engineering programme, it offered a deep dive into modern technologies, workflows, and architectural thinking. This repository documents key learnings, challenges, and personal reflections from the programme.

## Key Learnings

### Technologies Explored
- **Component Rendering**: Gained insight into how components behave across server and client environments.
- **Server vs Client Components**: Learned to evaluate rendering strategies for performance and user experience.
- **Redux State Management**: Understood how to manage complex state flows with predictable patterns.
- **Progressive Web Apps (PWA)**: Explored building resilient, offline-capable web applications.
- **React Native**: A personal highlight—transitioning from web to mobile development opened new creative possibilities.

### Why React Native Stood Out
React Native bridged the gap between web and mobile development, allowing me to apply familiar concepts in a new context. It sparked a deeper interest in cross-platform architecture and user experience design.

## Programme Pace and Learning Curve
The programme moved quickly, and several key concepts had a steep learning curve. Topics like Redux and SSR required multiple iterations to fully grasp. Despite the intensity, I’ve built a strong foundation to launch my frontend career.

### What Went Well
- **Structured Thinking**: Broke down complex problems into manageable steps.
- **UI/UX Awareness**: Prioritized user-centered design and cognitive load reduction.
- **Technical Architecture**: Explored scalable folder structures and provider patterns.
- **Messaging Clarity**: Refined documentation and internal communications for resonance and impact.

### What We Struggled With
- **Redux Debugging**: Tracing state mutations across components was initially challenging.
- **SSR vs CSR Decisions**: Required deeper architectural thinking to balance performance and interactivity.
- **Time Management**: Balancing hands-on coding with documentation and review cycles was demanding.

## Personal Takeaways
- Curiosity and persistence are key to navigating unfamiliar territory.
- Collaboration sharpens clarity—peer review and AI support made a tangible difference.
- Authenticity matters—whether in design or messaging, staying true to the user experience is essential.

## Looking Ahead
I’m excited to continue building scalable solutions.
